# Practical 2: Semantic HTML5 Pages with Accessibility-Ready Structure

## Objective
Create at least 10 linked static StudentHub pages using semantic HTML5 and accessibility-friendly structure.

## Pages
Home (`index.html`), About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, and Feedback. All 11 pages use consistent semantic header, navigation, main-content, and footer regions, link to one another with relative paths, and share the Practical 3 stylesheet.

## Accessibility checklist
- [x] HTML5 document type and English language metadata
- [x] Skip-to-content link on every page
- [x] Semantic header, named navigation, main, and footer regions
- [x] Descriptive page titles and logical heading hierarchy
- [x] Active page indicated in navigation
- [x] Form fields use labels and suitable native input types
- [x] FAQ content is visible without JavaScript
- [x] Local page links resolve within this practical`r`n- [x] Every page links to the shared Practical 3 stylesheet

## Run
Open `index.html` in a browser. Practical 2 uses semantic HTML and links to `../PRACTICAL-03/css/style.css` for its shared visual styling.

## Demonstration notes
Forms do not submit to a service or store data. Use demonstration data only. Profile and event content is sample or unconfirmed information. No JavaScript or external dependency is used here.
